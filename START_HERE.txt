═══════════════════════════════════════════════════════════════════════════
  HOW TO START (FIRST TIME)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Navigate to Project Directory
────────────────────────────────────────
  cd /home/user/FarmFactory


STEP 2: Initialize Everything (One Command!)
─────────────────────────────────────────────
  make init

  This single command will:
    ✓ Create .env file from .env.example
    ✓ Build all Docker images (~2-3 minutes)
    ✓ Start all services (PostgreSQL, Redis, Backend, Celery, Frontend)
    ✓ Initialize database with extensions
    ✓ Run database migrations
    ✓ Show you access URLs


STEP 3: Verify Everything is Running
─────────────────────────────────────
  make status     # Check service status
  make health     # Check service health


STEP 4: Access the Application
───────────────────────────────
  Open in your browser:

  Frontend:       http://localhost:3000
  Backend API:    http://localhost:8000
  API Docs:       http://localhost:8000/docs
  API ReDoc:      http://localhost:8000/redoc

═══════════════════════════════════════════════════════════════════════════
  PRODUCTION DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════

BEFORE DEPLOYING TO PRODUCTION:

1. Create production environment file:
   cp .env.example .env.production

2. Update critical settings in .env.production:
   - POSTGRES_PASSWORD=<strong-password>
   - REDIS_PASSWORD=<strong-password>
   - SECRET_KEY=$(openssl rand -hex 32)
   - ENVIRONMENT=production
   - DEBUG=false
   - ALLOWED_ORIGINS=https://yourdomain.com
   - Configure real SMTP settings

3. Deploy:
   make prod-deploy

4. Verify:
   docker-compose -f docker-compose.prod.yml ps

  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

SERVICES WON'T START
  make down
  make up
  make logs    # Check for errors

PORT ALREADY IN USE
  Edit .env and change ports:
    FRONTEND_PORT=3001
    BACKEND_PORT=8001

DATABASE CONNECTION ERRORS
  make db-reset    # WARNING: This deletes all data!

OUT OF MEMORY
  Increase Docker Desktop memory to 6GB+
  (Settings → Resources → Memory)

CLEAR EVERYTHING AND START FRESH
  make clean    # Removes containers, volumes, images
  make init     # Reinitialize
